# Words Change Worlds — Core Rebuild

这是一款独立的、可直接玩的文字规则解谜游戏。规则机制参考《Baba Is You》，但并非官方作品；没有使用原作代码、美术、音乐或关卡。**不是《Baba Is You》完整 1:1 复刻。**

这是一次核心重制，不是 v0.6 后面继续堆机制的 v0.7。旧版内容没有并入这次的关卡系统。

## 开始玩

最简单：双击 `play.html`，在电脑浏览器直接打开，不需要安装依赖或联网。

部署 GitHub Pages：将 `index.html`、`style.css`、`engine.js`、`levels.js`、`app.js` 上传到同一目录。入口文件是 `index.html`。

- 移动：方向键 / WASD；手机可点击方向按钮或滑动棋盘。
- 撤销：Z；重做：Y；重开：R。
- 选择关卡：右上角“关卡选择”。8 关均可直接选择。
- 进度只存储在当前浏览器（localStorage）；没有账号和服务器。

## 这次重做了什么

- 独立的棋盘、单位和文字规则模型。词牌是一种可推动的棋盘对象。
- 从左到右或从上到下拼句；移动词牌会即时重算规则。
- `NOUN IS PROPERTY` / `NOUN IS NOUN`，`AND` 并列主语或谓语，以及谓语的 `NOT` 否定。
- `YOU`、`WIN`、`PUSH`、`STOP`、`SINK`、`DEFEAT`、`OPEN`、`SHUT`、`HOT`、`MELT`、`WEAK`、`FLOAT` 的基础判定。
- 文本默认可推动（TEXT IS PUSH 的基础行为），推动链采用整条链成功才提交的事务式移动。
- 名词变形、规则即时失效、多个 YOU 同时移动、重叠获胜、基础接触判定。
- 8 个新制作的原创关卡，每关都有一条写在测试中的实际通关操作序列：打断规则、重新定义胜利、异地控制、远程变形、SINK 消除、双规则组合、否定优先级、自身成为胜利条件。
- 全新棋盘中心界面、规则实时显示、提示、选择关卡、存档和撤销重做。

## 明确的限制

此版本**没有**覆盖原作的完整引擎。尚未实现/验证的包括：复杂叠词与字母组词、NOT 主语、条件从句（ON/NEAR/FACING）、GROUP/EMPTY 的高级行为、HAS/MAKE、MOVE/SHIFT/SWAP/TELE/PULL/WORD 的完整互动、更多特殊规则、原作逐阶段的全部结算顺序及其极端冲突处理。不存在所谓“已经完全一样”的承诺。

工程目标是先用行为和关卡测试锁住核心概念，再迭代原作级别的系统行为。若以后扩展，应增加每一步棋盘状态与预期规则变化的独立验收，而不是靠关卡数量计进度。

## 测试

Node.js 18+：

```bash
node tests.js
```

共 28 项自动化测试，包括 8 个正式关卡的真实通关序列、规则解析与碰撞、以及模拟 DOM/Canvas 环境的界面逻辑冒烟测试。**测试不是实际浏览器渲染验证。** 本环境中 Chromium 截图尝试没有正常完成，因此本次未声称通过跨设备视觉验收。

## 文件

`engine.js` 为可单独测试的纯规则核心；`levels.js` 定义地图和文字；`app.js` 负责绘制和用户操作；`style.css` 为页面样式；`index.html` 为独立文件入口；`play.html` 打包了代码与样式，方便离线玩；`tests.js` 和 `tests/` 为测试；`scripts/build.js` 负责重新生成 `play.html`。

修改前备份旧的 Words Change Worlds 版本。若直接覆盖旧仓库，请**删除旧版与本版不一致的残留文件**，且不要把这些文件复制到另一个 Rule Is World 仓库。
