# Rule Is World

A small rule-rewriting puzzle game where the grammar is physically present in the room and can be pushed around until reality gives up.

## Design direction

This edition keeps the puzzle logic intact but deliberately avoids a polished "serious indie puzzle" look.

The interface is styled like:

- a badly supervised school notebook
- fridge notes from people who should not be making laws of physics
- photocopied instructions with suspicious annotations
- hand-cut word tiles
- sticky notes that disagree with each other

The absurdity is visual and verbal, not mechanical: every level still requires changing a rule to win.

## Controls

```text
Arrow keys / WASD   move
Z                   undo
R                   reset
Esc                 level select
```
